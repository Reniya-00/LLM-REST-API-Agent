# LLM + REST API Agent

## Project Overview
This project demonstrates how to connect a Large Language Model (LLM) with external REST APIs to build a simple AI agent.

The agent understands user questions, selects appropriate tools, retrieves external information and generates natural-language responses.

## Technologies Used
- Python
- Google Colab
- Groq API
- GPT-OSS 120B
- REST APIs
- Open-Meteo API
- JSON
- Python Requests

## Project Workflow
1. User submits a question.
2. LLM interprets the question.
3. LLM selects the appropriate function.
4. Python executes the function.
5. REST API retrieves weather information.
6. API response is passed back to the LLM.
7. LLM generates the final response.

## Key Concepts Learned
- LLM integration
- REST API communication
- HTTP GET requests
- JSON data handling
- Function calling
- Tool execution
- Basic AI agent architecture

## How to Run
1. Open the notebook in Google Colab.
2. Install the required libraries.
3. Obtain a Groq API key.
4. Enter your API key when prompted.
5. Run the notebook cells in order.
